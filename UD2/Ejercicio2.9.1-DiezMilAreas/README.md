# Ejercicio 9.1 · Diez mil áreas

> Actividad **9.1** de `UD02_Actividades.html`.

El área de 10 000 triángulos al azar con un hilo por triángulo y con un pool de 4 hilos, midiendo cuánto tarda cada forma.

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal ya viene puesta en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes DiezMilAreas
```
