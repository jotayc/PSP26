# Ejercicio 3.2 · Cuenta atrás

> Actividad **3.2** de `UD02_Actividades.html`.

Una tarea `CuentaAtras` recibe un nombre y un número n y escribe n, n-1… hasta 0, con 300 ms entre número y número. Se lanzan a la vez una cuenta desde 5 («cohete») y otra desde 3 («petardo»).

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal ya viene puesta en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes LanzaCuentas
```
