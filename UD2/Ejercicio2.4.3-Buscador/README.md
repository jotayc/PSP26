# Ejercicio 4.3 · Parar a tiempo

> Actividad **4.3** de `UD02_Actividades.html`.

Una tarea busca números primos sin parar hasta que la interrumpen, y entonces escribe cuántos ha encontrado y el último. El principal la deja trabajar dos segundos.

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal ya viene puesta en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes BuscarPrimos
```
