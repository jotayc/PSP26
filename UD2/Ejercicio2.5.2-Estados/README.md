# Ejercicio 5.2 · Ver los estados

> Actividad **5.2** de `UD02_Actividades.html`.

A partir de `VerEstados` (apartado 05), enseñar con `getState()` cuatro estados de dos hilos: NEW, RUNNABLE, TIMED_WAITING y TERMINATED, diciendo por qué está en cada uno.

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal ya viene puesta en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes VerCuatroEstados
```
