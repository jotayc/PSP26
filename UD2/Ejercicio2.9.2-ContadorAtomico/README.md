# Ejercicio 9.2 · Contador atómico

> Actividad **9.2** de `UD02_Actividades.html`.

El contador de la 6.1 con 500000 incrementos por hilo, con un `AtomicInteger`, comparando su tiempo con la versión `synchronized` y con la que falla.

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal ya viene puesta en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes Comparar
```
