# Ejercicio 1.6.2 · Escuchar al hijo

> Actividad **6.2** de `UD01_Actividades.html`.

Sin ficheros: lee la salida del hijo línea a línea desde el padre y escríbela con el prefijo
`[hijo]` delante.

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal y los argumentos ya vienen puestos en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes EscucharAlHijo
```
