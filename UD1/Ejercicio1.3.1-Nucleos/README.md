# Ejercicio 1.3.1 · Cuántos núcleos tienes

> Actividad **3.1** de `UD01_Actividades.html`.

Averigua cuántos núcleos ve Java en tu equipo y compáralo con lo que dice el sistema y con
las características del procesador. Si no coinciden, averigua por qué.

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal y los argumentos ya vienen puestos en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes Nucleos
```
