# Ejercicio 1.4.2 · Tres hijos a la vez

> Actividad **4.2** de `UD01_Actividades.html`.

Arranca tres copias de `QuienSoy` con nombres distintos y escribe un mensaje al acabar de
lanzarlas. Ejecútalo cinco veces y anota el orden en que salen las líneas.

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal y los argumentos ya vienen puestos en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes LanzaTres
```

Si el orden te sale idéntico las cinco veces no está mal: con hijos tan cortos y
el equipo descargado puede repetirse. Sube a seis hijos y vuelve a mirar.
