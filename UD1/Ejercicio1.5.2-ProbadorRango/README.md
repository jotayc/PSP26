# Ejercicio 1.5.2 · Enterarse de si ha ido bien

> Actividad **5.2** de `UD01_Actividades.html`.

Lanza `Rango` tres veces —con argumentos correctos, con los números al revés y sin
argumentos— y después de cada una interpreta el código de salida.

## Cómo ejecutarlo

**Desde NetBeans:** abre la carpeta como proyecto y pulsa *Run*. La clase
principal y los argumentos ya vienen puestos en el `pom.xml`.

**Desde la consola,** en la carpeta del proyecto:

```
mvn compile
java -cp target/classes ProbadorRango
```
